# Sound Files for Asteroids Game

Add the following sound files to this directory:

1. `laser-shoot.mp3` - A short laser sound for shooting (0.2-0.5 seconds)
2. `explosion.mp3` - An explosion sound for when asteroids are destroyed (0.5-1 second)
3. `thrust.mp3` - A rocket thrust sound (0.5-1 second)
4. `background-music.mp3` - Background music loop (30-60 seconds)

Recommended sources for free game sound effects:
- [OpenGameArt.org](https://opengameart.org/)
- [Freesound.org](https://freesound.org/)
- [Pixabay Sound Effects](https://pixabay.com/sound-effects/)
